# **App Name**: ACADEX

## Core Features:

- Authentification Rôles Firebase: Système de connexion sécurisé via Firebase Authentication distinguant les accès pour la direction, les enseignants, les élèves et les parents.
- Tableau de Bord de Performance: Visualisation en temps réel des statistiques scolaires (effectifs, taux de réussite) synchronisée avec Cloud Firestore.
- Générateur d'Observations IA: Un outil utilisant l'IA pour générer des commentaires académiques personnalisés et des rapports de synthèse basés sur les notes des élèves.
- Gestion des Bulletins Numériques: Saisie des notes et calcul automatique des moyennes avec stockage des documents officiels sur Firebase Storage.
- Centre de Notifications Premium: Système d'alertes en temps réel pour les absences, les annonces de la direction et les événements académiques.
- Portail Parent/Élève: Interface minimaliste permettant de consulter le calendrier, les devoirs et les suivis de paiements via localStorage pour la persistance locale.
- Archivage et Cloud SQL: Persistence des données historiques et académiques sécurisée pour assurer une scalabilité conforme aux exigences d'un SaaS moderne.

## Style Guidelines:

- Couleur primaire : Vert Forêt (#14532D) pour inspirer confiance et autorité académique.
- Couleur d'arrière-plan : Gris Clair (#F8FAFC), offrant une esthétique moderne et aérée propre aux dashboards SaaS.
- Couleur d'accent : Noir Élégant (#111827) pour le texte et les éléments structurels contrastés.
- Police 'Inter' : un style sans-serif grotesque, moderne et neutre, utilisé à la fois pour les titres et le corps du texte pour une lisibilité maximale.
- Utilisation exclusive de 'Tabler Icons' en tracé fin pour maintenir une esthétique premium et minimaliste.
- Structure avec barre latérale fixe (fond vert profond), barre supérieure blanche et contenu défilant pour une navigation fluide.
- Transitions douces entre les pages et effets de survol discrets sur les cartes de statistiques pour un rendu dynamique.
